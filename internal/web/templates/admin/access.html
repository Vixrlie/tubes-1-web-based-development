Level akses

Tidak ada akses — tidak dapat membuka database.

View Only — baca schema, data, dan riwayat.

View + Edit — baca, buat draft, dan jalankan migration. Data tetap hanya-baca.

Hak efektif melalui group

Tidak ada grant langsung ke user. Admin juga harus menjadi anggota group untuk memperoleh akses database.

Jika beberapa group memberi akses ke database yang sama, level tertinggi berlaku.
